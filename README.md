# East India Airline Customer Clustering

## Project Overview
This project explores customer segmentation for an East India airline case study using clustering techniques and exploratory data analysis. The objective is to identify groups of customers with similar characteristics and derive insights that may support customer relationship management and marketing strategies.

## Problem Statement
Understanding customer behaviour is important for airlines to improve customer engagement and develop targeted services. This case study investigates whether customer data can be grouped into meaningful segments using unsupervised machine learning.

## Objectives

- Clean and preprocess the data for analysis.
- Perform exploratory data analysis (EDA).
- Apply the clustering algorithm or algorithms used in the notebook.
- Visualize and interpret the resulting customer segments.
